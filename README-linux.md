Build this edition directly from a clone of BookWizOfficial, using the repository root that contains `package.json`. The optional `source-linux.zip` snapshot also contains a self-contained edition for people who prefer an archive.

## The desktop studio

BookWiz for Linux bundles the studio offline with desktop file dialogs, backup opening, File menus, and print/PDF controls. Books and preferences stay in local application storage.

## Downloads

Choose **AppImage** for a portable x64 application, or **DEB** for Debian/Ubuntu-family installation. These formats serve different installation workflows and are both retained in Releases.

## This source edition

The Electron host lives under `native/desktop/`. The Linux targets are AppImage and DEB for x64. Dependencies and contributor commands are in the build guide.

## Draft Flow

Explore a streamed continuation, pin story details, tune the prose and keep a passage when it belongs. Draft Flow follows this edition’s controls and your chosen theme. Its directions and previews stay with the chapter; model requests use your existing connections and require approval.
