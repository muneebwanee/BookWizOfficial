Build this edition directly from a clone of BookWizOfficial, using the repository root that contains `package.json`. The optional `source-tvos.zip` snapshot also contains a self-contained edition for people who prefer an archive.

## Read at a different scale

The Apple TV edition provides reading, read-aloud, a chapter outline board, and local book transfer. The TV view complements the writing studio on a personal device.

## Downloads

A **tvOS IPA** belongs to Apple TV and requires signing and provisioning appropriate to its installation channel. It is separate from an iPhone package.

## This source edition

The SwiftUI application lives under `native/apple/TV/`. Generate the shared project with XcodeGen on macOS and select **BookWiz-tvOS**. The deployment target is tvOS 17. Related Apple sources remain together in the project.
