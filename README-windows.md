Build this edition directly from a clone of BookWizOfficial, using the repository root that contains `package.json`. The optional `source-windows.zip` snapshot also contains a self-contained edition for people who prefer an archive.

## The desktop studio

BookWiz for Windows bundles the studio offline with native open/save dialogs, a File menu, backup opening, and print/PDF controls. Your library lives in the application's local storage.

## Downloads

Choose **BookWiz-VERSION-Windows-Setup.exe**. One installer contains x64 and ARM64 applications and selects the right one for the computer. Separate portable and architecture-specific installers are not part of the default release output.

## This source edition

The Electron host lives under `native/desktop/`. Its NSIS target combines both architectures with a stable installer filename. Desktop packaging is unsigned; signing status is recorded in release metadata. Contributor commands are in the build guide.
