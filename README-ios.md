## A writing room for iOS and iPadOS

The iPhone/iPad edition bundles the studio locally with system file access, print/export, native speech, five widgets, optional reminders, and an embedded Apple Watch companion. Compatible devices can use Apple Intelligence on iOS/iPadOS 26 or later when the model is available.

## Downloads

An **IPA** is an Apple device package. Installation requires a correctly signed and provisioned build for the chosen device or channel. The Watch companion is installed with its paired iPhone application.

## This source edition

`native/apple/project.yml` defines the Xcode project. Generate it with XcodeGen on macOS, then open **BookWiz-iOS** in Xcode. The deployment target is iOS/iPadOS 17. The five widgets provide book progress, goals, quick capture, writing time and bookshelf views. Related Apple targets share one project.
