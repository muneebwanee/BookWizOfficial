### Report a problem

Open an [issue](https://github.com/muneebwanee/BookWizOfficial/issues/new) with:

- Your BookWiz version, operating system, and browser or installed edition.
- The steps that lead to the problem, what you expected, and the exact error.
- Whether it repeats, and a cropped screenshot when it clarifies the interface.

A small invented example is best. Keep manuscripts, API keys, vault passphrases, signing identities and personal information out of public reports. For provider failures, include the provider and model ID without the key.

### Security and private reports

For a vulnerability or a problem involving private data, use the contact information on [my GitHub profile](https://github.com/muneebwanee) before posting sensitive details publicly. Share the smallest redacted example that demonstrates the problem.
