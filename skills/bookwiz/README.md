# BookWiz skill files

[Start with SKILL.md](SKILL.md). This folder is self-contained: copy the whole directory, including scripts, references, templates and licenses, into an Agent Skills host.

For the extracted plugin ZIP, use its root `install.py`. When copying this folder directly, use `python3 scripts/install_skill.py --agent codex --scope project --project /path/to/project`.
