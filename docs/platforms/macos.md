These instructions apply to the extracted `source-macos.zip` edition. Open its folder containing `package.json` before running build commands.

## The desktop studio

The Mac edition bundles the studio offline with system file dialogs, File menus, backup opening, and print/PDF controls. It keeps a local library, separate from the browser edition.

## Downloads

Choose **BookWiz-VERSION-macOS.dmg**. Open the disk image and move BookWiz to Applications. The universal application contains Intel and Apple Silicon code, so no chip-specific choice is needed.

## This source edition

The Electron host lives under `native/desktop/`. The default Mac target is a universal DMG. Current packaging is unsigned and not notarized; release metadata records that status. Building the DMG requires macOS.
