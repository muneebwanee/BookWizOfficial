Build this edition directly from a clone of BookWizOfficial, using the repository root that contains `package.json`. The optional `source-android.zip` snapshot also contains a self-contained edition for people who prefer an archive.

## Your pocket studio

The Android edition bundles the studio offline and adds system file opening, saving, printing, native speech, Back navigation, nine home-screen widgets, and optional local writing reminders. Books and preferences stay on the device.

The widgets include a live clock with today’s writing progress, four writing shortcuts, a seven-day progress chart, and a daily writing invitation. Each tap opens its named page or controls. See the [widget guide](../WIDGETS.md) for sizes, privacy and updating older placements.

**PDF options** opens the native print/save sheet with the book’s chosen trim and margins. Use **Save as PDF** in that sheet. Text reflows to the paper you select, so a service that chooses Letter fills that page instead of shrinking the book into its center. LaTeX source export remains available for a computer with XeLaTeX or Tectonic; Android PDF export does not require a localhost service.

## Downloads

Choose the **APK** from official Releases for direct installation. An **AAB** is the store bundle. Packages marked `development` use the development signing identity. Android updates require the same signing identity as the installed app.

## This source edition

`native/android/` contains the Java/WebView host. The shared studio is in `dist/`. Build tools include a pinned, checksum-verified bundletool downloader. Android requires JDK 21; the full commands are in the build guide.
