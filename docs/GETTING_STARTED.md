## Make a book

Open the library and choose **New book**. The brief collects the language, genre, physical trim, visual direction, front matter, target length, voice, premise, and optional people and places. Review it before generating an outline. Model actions require a selected connection and approval; the manuscript editor also works for writing by hand.

An outline is a working plan. Edit titles and beats before accepting it. Existing chapters remain yours when a plan changes.

## Settle into the manuscript

| Tool | Use it for |
| :--- | :--- |
| **Back to writing** | Return to the chapter and scroll position you left. |
| **Focus** | Give the chapter the screen. |
| **Versions** | Preview and restore earlier saved chapter pages. |
| **Characters & worlds** | Keep the story's facts close to the prose. |
| **The Red Pen** | Discuss passages and review proposed revisions. |
| **Read** | Hear and inspect the manuscript away from the editor. |

Undo/redo covers recent text and title edits during the session. Saved Versions offer longer-lived recovery. A restore keeps the current page first, within the retained-version budget.

## Keep a copy

Export an individual-book or workspace **JSON backup** regularly. A backup carries books and story notes, while excluding API keys. Import previews the contents and adds copies instead of replacing existing projects or credentials.

Libraries are local to their browser or installed edition. Use a backup when changing browser, address, device, or app. Saved versions help with edits; they do not replace an independent backup.

## Make it a finished object

Open **Cover & publish** to choose a cover direction, adjust typography and composition, and inspect the book proof. Export EPUB for readers, Markdown for text workflows, JSON for backups, print/PDF for a proof, or LaTeX source for a typesetting workflow. Print requirements vary by printer and trim.

## Useful keys

| Shortcut | Action |
| :--- | :--- |
| **⌘/Ctrl K** | Find books, text, notes, profiles, and actions. |
| **⌘/Ctrl Z** | Undo a chapter edit. |
| **⌘/Ctrl Shift Z** | Redo a chapter edit. |
| **⌘/Ctrl S** | Keep a chapter version while writing. |
| **⌘/Ctrl Shift F** | Enter or leave focus. |

Help & support inside the studio lists the available shortcuts and device tools.
