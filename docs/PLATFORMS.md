[Draft Flow](DRAFT_FLOW.md) is built into the Android, iPhone/iPad, Windows, macOS, Linux and web writing studio. It follows the selected BookWiz theme and uses the existing hosted, local or compatible device-model connection.

## The same book, separate libraries

Installed editions bundle the writing interface locally; they do not load the published website at launch. Each installation keeps its own library. JSON backups move books and notes between editions without copying API secrets or device permissions.

Web home-screen shortcuts retain browser capabilities. Native widgets, Apple Intelligence, and closed-app reminders depend on the actual host and device. Model availability also depends on hardware, language, region, installed services, and provider access.

Package formats and installation notes are in the [release guide](RELEASE.md). Native source and build details are in [Building BookWiz](BUILDING.md).
