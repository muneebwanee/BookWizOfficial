The content category is determined by its role, not only its extension. A standalone wordlist, regex catalog, or rubric remains CC BY 4.0 when stored as JSON, YAML, CSV, or plain text. The code that reads or processes that resource remains BWNCL. Regex expressions embedded in application code do not change that code's license.

## Contributing code

BWNCL permits inspection, private non-commercial use and modifications, and GitHub forks for study and non-commercial upstream contributions. Its rules for distribution, commercial use, attribution, and contribution grants remain in the [full code license](../LICENSES/BWNCL-1.0.txt). BWNCL is a source-available license rather than an OSI-approved open-source license.

Submit code changes against the editable source tree in the repository. The retained platform source ZIPs are distribution snapshots. Contributors do not need to unpack or rebuild those ZIPs to propose a source change.

## Reusing documentation and catalogs

CC BY 4.0 permits sharing and adaptation, including commercial reuse, with appropriate attribution, a license link, and an indication of changes. A useful attribution identifies **BookWiz by muneebwanee**, links the [official repository](https://github.com/muneebwanee/BookWizOfficial), and links [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Documentation and catalog contributions are submitted under CC BY 4.0. Code contributions use BWNCL and its contribution grant. Contributors keep their copyright. Do not submit material you cannot license on those terms.

Third-party permissions are preserved. Neither BookWiz license replaces an upstream license or removes a notice.
